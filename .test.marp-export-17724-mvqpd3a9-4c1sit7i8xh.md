## Вариант 1

1. Для каждой из приведенных программ оцените время ее работы. Объясните разницу в асимптотике.

```cpp
int f(int n) { 
    if (n == 0)  
        return 1; 
    else 
        return f(n / 3) + f(n / 3); 
}  

int g(int n) { 
    if (n == 0)  
        return 1; 
    else 
        return 2 * g(n / 3); 
}
```

2. Сравните асимптотики $O(n \log^2 n)$ и $O(n^{1.05})$. При достаточно больших $n$, какая из них растёт медленнее? Приведите обоснование через предел отношения $\lim_{n \to \infty} \frac{n \log^2 n}{n^{1.05}}$. Укажите, насколько заметна разница на практике при $n = 10^6$: оцените отношение значений (можно использовать $\log_2 10^6 \approx 20$)

3. Докажите по индукции, что если $T(n) = 2T(n/2) + n$, то $T(n) = O(n \cdot \log{n})$ (усложнение: показать для $T(n) = 2T(n/2+10) + n$)

4. Дан отсортированный по неубыванию массив $a$ и число $X$. Определите, есть ли в массиве два элемента, сумма которых равна $X$. Время работы алгоритма должно быть $O(n)$.
