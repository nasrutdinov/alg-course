# Конспект: Фильтр Блума (Bloom Filter)

**Фильтр Блума** — это вероятностная структура данных, предложенная Бартоном Блумом в 1970 году. Она позволяет проверять, содержится ли элемент в множестве, экономя память ценой допуска небольшой вероятности ошибки.

---

## 1. Основные понятия и принцип работы

Фильтр состоит из двух компонентов:
1. **Битовый массив** фиксированного размера $m$ (изначально заполнен нулями).
2. **$k$ независимых хеш-функций**, которые отображают элемент в один из $m$ индексов массива.

### Операции:
* **Добавление (`add`):** Элемент пропускается через $k$ хеш-функций. В битовом массиве по полученным $k$ индексам устанавливаются единицы (`1`).
* **Проверка (`contains`):** Элемент снова пропускается через $k$ хеш-функций. 
  * Если **хотя бы один** бит по полученным индексам равен `0` — элемента в множестве **точно НЕТ**.
  * Если **все** биты равны `1` — элемент **возможно ЕСТЬ** (но это не гарантировано).

---

## 2. Ключевые особенности

### Плюсы:
* **Эффективность памяти:** Занимает в разы меньше места, чем сами элементы или хеш-таблицы.
* **Скорость:** Время добавления и проверки $O(k)$, где $k$ — число хеш-функций (обычно от 3 до 10).
* **Отсутствие ложноотрицательных срабатываний (False Negatives):** Если фильтр говорит «нет» — это 100% правда.

### Минусы:
* **Возможны ложноположительные срабатывания (False Positives):** Фильтр может сказать «да», хотя элемента нет (из-за коллизий хешей).
* **Невозможность удаления:** В классическом фильтре нельзя удалить элемент, не задев другие (так как несколько элементов могут делить одни и те же биты). *Существует модификация Counting Bloom Filter, где хранятся счетчики, но она требует больше памяти.*

---

## 3. Примеры использования в реальных системах

1. **Базы данных (Cassandra, HBase, RocksDB):**
   Перед чтением данных с медленного диска проверяется фильтр Блума. Если его нет в фильтре — запрос к диску не делается. Это колоссально ускоряет работу БД.
2. **Веб-браузеры (Safe Browsing):**
   Браузер хранит локальный фильтр Блума с хешами миллионов фишинговых/вредоносных URL. Если URL нет в фильтре — сайт безопасен. Если есть — браузер делает точный запрос к серверу Google/Яндекс для подтверждения.
3. **Защита кэша (Cache Penetration):**
   Чтобы злоумышленник не «пробил» кэш и не начал долбиться в базу данных запросами несуществующих ID, перед обращением к БД проверяют фильтр Блума.
4. **Социальные сети и мессенджеры:**
   * **Medium:** Хранит хеши статей, которые пользователь уже прочитал, чтобы не рекомендовать их повторно.
   * **Facebook / LinkedIn:** Проверка занятости username или email при регистрации.
5. **Синхронизация распределенных систем:**
   Быстрая проверка того, различаются ли данные на двух разных серверах (сравнение их фильтров Блума).

---

## 4. Математика (как настроить размер)

Вероятность ложноположительного срабатывания ($p$) зависит от размера массива ($m$), количества элементов ($n$) и числа хеш-функций ($k$).

Оптимальные значения рассчитываются по формулам:
* **Размер массива:** $m = -\frac{n \ln p}{(\ln 2)^2}$
* **Число хеш-функций:** $k = \frac{m}{n} \ln 2$

*Пример: Для 1 млн элементов и вероятности ошибки 1% ($p=0.01$) нужен массив размером ~9.5 Мбит (около 1.2 МБ) и 7 хеш-функций.*

## 5. Реализация на Python

В продакшене обычно используют библиотеку `pybloom_live` или `mmh3` (MurmurHash3). Ниже приведен **учебный пример** с использованием стандартной библиотеки `hashlib`, демонстрирующий суть алгоритма.

```python
import hashlib

class BloomFilter:
    def __init__(self, size, num_hashes):
        """
        :param size: Размер битового массива (m)
        :param num_hashes: Количество хеш-функций (k)
        """
        self.size = size
        self.num_hashes = num_hashes
        self.bit_array = [0] * size

    def _get_indices(self, item):
        """Генерирует k индексов для одного элемента."""
        indices = []
        for i in range(self.num_hashes):
            # Добавляем "соль" (i), чтобы эмулировать k разных хеш-функций
            data = f"{i}:{item}".encode('utf-8')
            # Берем sha256, берем первые 8 байт и конвертируем в целое число
            hash_bytes = hashlib.sha256(data).digest()[:8]
            hash_int = int.from_bytes(hash_bytes, byteorder='big')
            indices.append(hash_int % self.size)
        return indices

    def add(self, item):
        """Добавляет элемент в фильтр."""
        for idx in self._get_indices(item):
            self.bit_array[idx] = 1

    def contains(self, item):
        """Проверяет наличие элемента. 
        Возвращает False, если элемента точно нет.
        Возвращает True, если элемент, возможно, есть."""
        for idx in self._get_indices(item):
            if self.bit_array[idx] == 0:
                return False  # Точно нет
        return True  # Возможно есть


# ==============================
# Пример использования
# ==============================
if __name__ == "__main__":
    # Создаем фильтр: размер 1000 бит, 3 хеш-функции
    bf = BloomFilter(size=1000, num_hashes=3)
    
    # Добавляем элементы
    words_to_add = ["apple", "banana", "cherry", "date"]
    for word in words_to_add:
        bf.add(word)
        print(f"Добавлено: {word}")

    print("\n--- Проверка существующих элементов ---")
    for word in words_to_add:
        print(f"'{word}' в фильтре? -> {bf.contains(word)}") # Всегда True

    print("\n--- Проверка отсутствующих элементов ---")
    test_words = ["elderberry", "fig", "grape", "kiwi", "lemon", "mango", "orange"]
    false_positives = 0
    
    for word in test_words:
        result = bf.contains(word)
        status = "Ложное срабатывание (False Positive)!" if result else "Отсутствует"
        print(f"'{word}' в фильтре? -> {result} ({status})")
        if result:
            false_positives += 1
            
    print(f"\nИтого ложных срабатываний: {false_positives} из {len(test_words)}")
```

### 💡 Советы для Production (Python):
1. **Не используйте `hashlib` для больших данных.** Он медленный. Используйте библиотеку **`mmh3`** (MurmurHash3), она создана для хеш-таблиц и фильтров Блума.
2. **Используйте `bitarray`.** Хранить биты в списке Python (`[0, 1, 1...]`) — расточительно для памяти (один элемент списка весит 28 байт). Используйте библиотеку `bitarray` или `numpy`, где 1 бит занимает ровно 1 бит.
3. **Counting Bloom Filter.** Если вам критически важно уметь удалять элементы, замените битовый массив на массив целых чисел (счетчиков). При добавлении инкрементируйте, при удалении — декрементируйте.
